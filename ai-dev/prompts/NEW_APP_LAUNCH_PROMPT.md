# 新アプリ立ち上げ用プロンプト（コピー用テンプレート）

## これは何か

プロジェクトオーナーが **Gem に渡して新しいアプリを立ち上げる**ときに使う、様式固定のプロンプトです。

**使い方:**

1. 下の「▼ ここからコピー ▼」〜「▲ ここまでコピー ▲」の間をコピーする
2. `< >` で囲まれた部分（プレースホルダー）を、これから作るアプリの内容で埋める
3. 埋め終わったものを Gem（または Gemini・Claude）に渡す

このプロンプトどおりに進めれば、新しいアプリに **共通ルールを継承した `GEMINI.md` / `CLAUDE.md` が自動的に生成・配置され**、
GitHub を正本としたリポジトリ構成になります。

1. git status で内容を確認する

   （mainに直接pushせず、作業用ブランチを切ってPull Requestを作成することを推奨する）

- 配置したディレクトリ（Cloud Shellの場合）

- git push が完了しているか
- 次にやるべきこと（機能追加が必要なら何を作ればよいか）

不明な点、判断に迷う点があれば、作業を止めて確認してください。

## 補足（この運用の背景）

- このプロンプトは、共通開発ルール（`ai-dev/rules/DEVELOPMENT_RULES.md`）と
  MDテンプレート（`ai-dev/templates/`）を前提にしています。それらを更新した場合、
  このプロンプト自体を書き換える必要は基本的にありません（URL参照のため自動的に最新が反映されます）。
- Gemini・Claude のどちらに渡しても同じ内容で動作するように書かれています。
  最初にどちらのAIで開発を始めても、後から他方のAIに引き継げます。
- 「対象アプリとGitHubリポジトリの対応」を毎回明記させることで、
  誤って別のリポジトリを操作する事故を防いでいます（共通ルール第6章）。
